# Website Template (Static)

A modern, responsive, accessible landing page built with vanilla HTML, CSS, and JavaScript.

## Quickstart

- Open `index.html` directly in your browser; or
- Serve locally (recommended) with Python:

```bash
python3 -m http.server 4321 --directory /workspace/website
```

Visit `http://localhost:4321`.

## Customize

- Update branding and content in `index.html` (headings, copy, nav links).
- Tweak colors, spacing, and component styles in `styles.css`.
- Edit interactions (theme toggle, mobile nav) in `script.js`.

## Deploy

Upload the contents of `/workspace/website` to any static host (GitHub Pages, Netlify, Vercel, S3, etc.).

## Accessibility

- Semantic landmarks (`header`, `nav`, `main`, `footer`)
- Sufficient color contrast and focus styles
- ARIA attributes for menu toggle and logos
